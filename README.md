# Usando notebookLM para aprender Redes de Computadores
Projeto feito para a plataforma da DIO para por em prática os conhecimentos do notebooklm. O objetivo desse notebook veio de um interesse de aprender de forma eficiente e prática o assunto de Redes de Computadores e um pouco de outros assuntos que cruzam com o tópico, como Cibersegurança, Sistemas Operacionais e Nuvem.

Foi bastante curioso como o próprio NotebookLM as vezes ignora algumas sugestões, em específico um dado momento quando eu decidi adicionar um pouco de fontes sobre Sistemas Operacionais para poder enriquecer mais o notebook, eu havia pedido que ele se limitasse a 5 fontes, todavia ele trouxe 16, o que ao analisar são fontes boas que vão agregar no notebook desenvolvido, porém não foi exatamente o que eu pedi.
